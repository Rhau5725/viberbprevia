# Viver Produtos Naturais — prévia

Prévia estática e responsiva da landing page da Viver, criada a partir do logo e do posicionamento visual enviado na conversa.

## Abrir

Abra `index.html` diretamente no navegador ou sirva a pasta com qualquer servidor HTTP local.

## Observações

- O catálogo, disponibilidade e preços são demonstrativos.
- O CTA aponta para o Instagram informado: `@viver_barao`.
- A seção “Nossa rotina” usa uma composição ilustrada própria, sem o print do Instagram.
- Os dados oficiais, contatos e integração com o repositório entram na próxima etapa.
